# Culture Talk Stratification

Replication package for:

> Lizardo, Omar. 2016. "Why 'cultural matters' matter: Culture talk as the mobilization of cultural capital in interaction." *Poetics* 58: 1–17. DOI: [10.1016/j.poetic.2016.09.002](https://doi.org/10.1016/j.poetic.2016.09.002)

The paper examines the stratification of cultural talk across various domains (movies, music, books, visual arts, dramatic performances), looking at how engagement and demographic factors (education, income, age, gender, city) intersect to shape cultural conversation.

This repository contains only the data and code required to replicate the tables and figures in the published paper.

## Repository structure

```text
├── R/                              # R scripts with the computational pipeline
│   ├── 01_data_prep.R              # Data wrangling and variable preparation
│   └── 02_analysis.R               # Main ordered probit models and factor analyses
├── dat/                            # Data
│   ├── NSS-2002-2004-using.dta     # Original Stata dataset
│   └── small.rds                   # Processed analysis dataset (generated by 01_data_prep.R)
├── renv.lock                       # renv lockfile for exact package versions
└── renv/                           # Project-local R library configuration
```

## Prerequisites

R (>= 4.x). The environment is managed with [renv](https://rstudio.github.io/renv/); run `renv::restore()` to install the exact package versions recorded in `renv.lock`.

Key packages used by the pipeline:

| Package          | Version  | Role                                              |
|------------------|----------|---------------------------------------------------|
| haven            | 2.5.5    | Reading the original Stata dataset                |
| dplyr            | 1.2.1    | Data wrangling                                    |
| MASS             | 7.3-66   | Ordered probit models (`polr`)                    |
| psych            | 2.6.5    | Principal-components factor analysis              |
| modelsummary     | 2.6.0    | Regression tables                                 |
| marginaleffects  | 0.32.0   | Average marginal effects for the figures          |
| ggplot2          | 4.0.3    | Figures                                           |
| patchwork        | 1.3.2    | Figure composition                                |

## How to replicate

1. Clone this repository.
2. Run `renv::restore()` to install the locked package versions.
3. Run the pipeline in order:

```r
source("R/01_data_prep.R")
source("R/02_analysis.R")
```

Tables are written to `Tabs/` and figures to `Plots/`.
